# Tester rezystancji izolacji Riso

## Opis
Tester rezystancji izolacji Riso jest urządzeniem przeznaczonym do sprawdzania mierników rezystancji izolacji firm takich jak Sonel, Metrel oraz innych producentów.

Urządzenie zostało zaprojektowane jako **tester funkcjonalny**, umożliwiający bieżącą kontrolę mierników pomiędzy wzorcowaniami laboratoryjnymi, zgodnie z dobrą praktyką metrologiczną.

Tester pozwala na sprawdzenie wskazań miernika dla trzech wybranych oporności wzorcowych.

## Zastosowanie
- Sprawdzanie poprawności wskazań mierników rezystancji izolacji  
- Codzienna kontrola sprawności sprzętu pomiarowego  
- Narzędzie dla elektryków, firm pomiarowych, laboratoriów oraz działów UR  

## Zakres rezystancji testowych
Zestaw rezystorów o znanych wartościach:
- 100 MΩ  
- 200 MΩ  
- 1 GΩ  

## Budowa i wyposażenie
- Zamknięta obudowa drukowana w technologii 3D z PLA  
- Bezpieczne gniazda bananowe  
- Rezystory wzorcowe  

## Ważne informacje
- Urządzenie **nie jest wzorcem** ani **przyrządem wzorcowanym**  
- Służy wyłącznie do **sprawdzeń funkcjonalnych**  
- Nie zastępuje wzorcowania laboratoryjnego  
- Idealne narzędzie do codziennej kontroli mierników rezystancji izolacji  

## Uwaga
Tester należy stosować wyłącznie do kontroli funkcjonalnej. Oficjalne wzorcowanie i pomiary odniesione należy wykonywać w akredytowanych laboratoriach.



# Riso Insulation Resistance Tester

## Description
Riso Insulation Resistance Tester is a functional testing device designed for checking insulation resistance meters from manufacturers such as Sonel, Metrel, and others.

The device was created as a **functional tester**, enabling routine verification of measuring instruments between laboratory calibrations, in accordance with good metrological practice.

The tester allows verification of meter readings using three selected reference resistance values.

## Applications
- Verification of insulation resistance meter readings  
- Daily functional checks of measuring equipment  
- Tool for electricians, measurement companies, laboratories, and maintenance departments  

## Test Resistance Range
The device includes a set of precision resistors with known values:
- 100 MΩ  
- 200 MΩ  
- 1 GΩ  

## Construction and Equipment
- Closed enclosure, 3D printed from PLA  
- Safety banana sockets  
- Precision resistors  

## Important Information
- This device is **not a reference standard** and is **not a calibrated instrument**  
- It is intended for **functional checks only**  
- It does **not replace laboratory calibration**  
- Ideal for everyday condition checks of insulation resistance meters  

## Disclaimer
Use this device only for functional verification purposes. Always rely on certified laboratories for official calibration and traceable measurements.
